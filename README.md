# GIMMD

在原神游戏内播放 MMD 动作，调整镜头，并使用角色模型进行舞蹈展示和拍摄。

GIMMD 提供图形控制台，支持当前角色播放、本地演员创建、相机控制，以及动作文件内的部分面部表情。当前适配 **Windows x64 / 原神国服 7.2.0**，功能仍在完善中；不同角色和动作的效果可能有差异。

## 可以做什么

| 功能 | 说明 |
| --- | --- |
| 播放动作 | 为当前出场角色播放 VMD，支持暂停、继续、跳转、循环和恢复游戏动画 |
| 播放音乐 | 为当前角色的动作搭配 WAV 音频，并调整音频偏移 |
| 创建本地演员 | 直接载入目录中的角色，或复制已载入的角色模型；最多保留三名演员 |
| 调整相机 | 播放前将镜头移到角色正面，手动调整位置、角度和视野，或使用相机 VMD |
| 拍摄演员 | 隐藏当前角色，将镜头移到或跟随指定演员，结束后恢复 |
| 播放表情 | 读取动作 VMD 内的眨眼、笑眼、部分嘴形和眉形；需要手动开启 |
| 保存工程 | 保存素材路径与设置，下次打开继续使用；支持导入 `set.ini` |
| 编排运镜 | 添加相机关键帧、预览运镜并导出相机 VMD |

这里的“本地演员”是本机用于拍摄的角色模型副本。虽然可以创建三名演员，目前一次选择一名演员播放动作。

## 从源码安装

### 1. 准备环境

- Windows x64。
- 与当前适配匹配的原神国服 7.2.0 客户端。即使版本号相同，可执行文件发生变化后也可能需要重新适配。
- Visual Studio 或 Visual Studio Build Tools，安装“使用 C++ 的桌面开发”，包含 MSVC x64 工具和 Windows SDK。
- Python 3.10 或更新版本，带 `tkinter`。可运行 `python -m tkinter` 检查是否能打开测试窗口。
- 自备完整动作 `.vmd`；音乐 `.wav` 和相机 `.vmd` 均为可选。

仓库不包含游戏文件、角色资源、舞蹈素材和本机测试工程。普通构建使用仓库内已有的适配文件。

### 2. 获取并构建

克隆仓库，也可以下载源码 ZIP 后解压。在项目根目录打开 PowerShell：

```powershell
git clone https://github.com/Qi-2007/GIMMD.git
cd GIMMD
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-7.2.ps1
```

如果使用下载的 ZIP，直接进入解压后的目录执行最后一条命令。

构建成功后会生成 `build-studio-7.2-face`，这也是控制台默认使用的构建目录。脚本会自动运行核心和模拟运行时检查。

### 3. 启动控制台

在项目根目录运行：

```powershell
python .\src\gui\player_gui.py
```

也可以用启动脚本指定自己的 Python 路径，例如：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-gui.ps1 -PythonPath "C:\Python312\pythonw.exe"
```

请将示例路径替换为实际安装位置。`start-studio.cmd` 会调用同一个启动脚本；直接双击时使用脚本预设的 Python 路径，找不到 Python 时请使用上面的方式启动。

## 第一次播放

1. 启动游戏，进入大世界，让要播放动作的角色出场。
2. 打开控制台的 **动作与播放** 页，确认构建目录为 `build-studio-7.2-face`。
3. 选择完整的 **动作 VMD**。需要配乐时，再选择 **音频 WAV**。
4. 点击游戏进程旁的 **刷新**，选择当前游戏进程。
5. 点击 **连接并注入（待命）**，等待连接成功。
6. 点击 **播放 / 继续**。默认开启的 **播放前相机归位** 会先让镜头正对角色；可以取消勾选。
7. 使用 **暂停**、进度条、**跳转（秒）** 或 **循环** 控制播放。
8. 播放完成后，点击 **恢复游戏动画**。不用工具时，点击 **退出注入会话**，等待恢复和清理完成。

播放前会自动初始化当前角色的骨骼姿态，减少待机动画对动作的影响。动作结束时会保留末帧，需要恢复游戏动画时使用对应按钮。暂停和恢复游戏动画都不会退出整个会话，可以继续选择其他动作。

## 使用本地演员

1. 先连接会话，在 **动作与播放** 页选好动作 VMD。
2. 打开 **本地演员** 页，选择角色并点击 **直接加载并创建**。这种方式无需先打开角色预览。
3. 若要复制当前或已载入的模型，选择相应来源，点击 **复制已载入模型**。
4. 选择创建后的 **演员槽位**，点击 **播放所选 VMD**。
5. 使用演员页的 **暂停**、**继续**、**恢复姿态** 控制动作；使用 **移除全部演员** 清理副本。

“当前角色”和 `Ambor` 来源使用复制方式。最多创建三名演员；首次直接载入可能需要等待资源加载。同一会话累计直接加载达到 16 次时，请退出会话后重新连接。

演员播放目前不包含脚部 IK，也不与音频、相机 VMD 同步。需要动作、音乐和相机轨道同步时，使用当前角色播放流程。

## 调整镜头

**正面取景**：在播放页勾选 **播放前相机归位**。镜头会在开始动作前移动到当前角色正面，并清零手动偏移；之后可继续调整距离、高度和角度。

**手动机位**：在 **相机轨道** 页勾选 **仅手动机位（无需相机 VMD）**，连接后点击 **开启相机**。修改位置、偏航、俯仰、滚转和 FOV，再点击 **应用机位**。**复位偏移** 清除手动调整，**关闭相机并恢复** 返回原视角。

**相机 VMD**：选择相机文件，取消“仅手动机位”，开启相机后与当前角色动作一起播放。镜头轨迹按会话的起始视角对齐；开启正面归位时，会从归位后的视角出发。FOV 填 `0` 时使用轨道值。

**演员取景**：先开启手动相机，再到 **本地演员** 页选择槽位，使用 **移到所选槽位** 或 **跟随所选槽位**。需要画面中只显示演员时，可点击 **隐藏当前角色**，拍摄结束后点击 **显示当前角色**。切换游戏角色前，先恢复显示。

相机不自动避开地形和墙体，取景位置需要手动调整。

## 开启面部表情

在 **动作与播放** 页勾选 **播放 VMD 内的面部表情**，然后开始一次新的动作播放。该选项默认关闭，同时适用于当前角色和载入的演员。

目前支持眨眼、笑眼、左右单眼眨眼，以及部分张嘴、微笑和眉形。纳西妲搭配《Moonride》的表情已完成实测，修正了游戏自身表情干扰导致的抽搐。

表情必须包含在所选动作 VMD 内；尚不支持单独导入表情 VMD、全部日语口型或目线骨骼。不同模型的表情对应关系仍可能存在差异。

## 素材与工程

- **动作**：使用带全身骨骼轨道的 VMD。只有目线或表情的文件不能作为完整动作播放。
- **音乐**：使用 16 位 PCM WAV，单声道或双声道，采样率 8–192 kHz，文件不超过 64 MiB。MP3 等格式需要先自行转换。
- **音频偏移**：正值提前音乐，负值延后音乐，单位为秒。
- **相机**：使用透视相机 VMD，当前不支持包含正交投影关键帧的文件。
- **工程**：点击 **保存工程** 保存设置，使用 **打开工程** 恢复。工程记录素材路径，不会将素材打包进去；移动素材或换电脑后需要重新选择路径。
- **set.ini**：已有配套配置时，可使用 **导入 set.ini** 导入。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 找不到游戏进程 | 确认游戏已启动，再点击“刷新”；重启游戏后需要重新选择进程 |
| 提示找不到 Python | 使用自己的 Python 运行 `src/gui/player_gui.py`，或为启动脚本传入 `-PythonPath` |
| 提示缺少 `tkinter` | 为当前 Python 安装 Tcl/Tk 支持，再运行 `python -m tkinter` 检查 |
| 找不到构建清单或构建不匹配 | 先完成构建，选择整个 `build-studio-7.2-face` 目录；不要混用不同构建中的文件 |
| 游戏版本或接口校验失败 | 使用与适配匹配的客户端；游戏更新后需等待对应适配，改文件名不能解决 |
| 连接时提示访问被拒绝 | 确认工具与游戏的运行权限匹配；游戏以管理员身份运行时，工具也需要相应权限 |
| 角色动作绑定失败 | 保持角色在大世界，退出当前会话后重新连接；仍失败时保留日志并反馈角色和动作信息 |
| 动作能播放，但没有表情 | 确认已开启表情选项，且动作 VMD 本身包含受支持的表情轨道 |
| 游戏原有音乐与配乐重叠 | 当前版本的游戏 BGM 暂停尚未适配，可先在游戏设置中手动降低音乐音量 |
| 动作沉地、脚滑或穿模 | 尝试平坦地面和其他动作；不同角色比例、脚部 IK 与地形适配仍有限制 |

当前角色播放主要验证了男主与纳西妲；直接加载已验证纳西妲等角色，尚未逐个确认所有角色和动作。表情和部分拍摄功能仍属于实验功能。

## 反馈问题

请在仓库 Issues 中说明角色、客户端版本、使用的是当前角色还是本地演员、复现步骤，以及相关素材是否只有动作、表情或目线轨道。

使用启动脚本时，GUI 日志位于 `logs/`；每次连接生成独立的 `sessions/` 子目录，其中的状态和诊断报告有助于定位问题。分享报告前可检查其中的本机路径，动作与音乐素材无需随报告上传。
