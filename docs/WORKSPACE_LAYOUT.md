# 工作目录与本地文件

版本库包含 `src/`、`scripts/`、`tests/`、`data/`、`docs/`、`references/`、`third_party/` 以及根目录构建和启动入口。`src/generated/` 中的版本固定接口与角色目录是编译输入，需要提交。

以下是本机文件，由 `.gitignore` 排除：

| 目录 | 用途 |
| --- | --- |
| `build-studio-7.2-face/` | 当前 GUI 默认构建，可用 `scripts/build-7.2.ps1` 重建 |
| 其他 `build*/` | 构建输出、测试夹具、离线研究依赖或历史工程引用的版本 |
| `projects/` | 用户保存的工程，可能包含本机素材绝对路径 |
| `testmmd/` | 用户提供的 VMD、音频及其他素材 |
| `sessions/` | 独立运行会话、诊断报告及素材副本 |
| `logs/` | GUI 日志及本地操作日志 |
| `archives/` | 已归档的历史调查资料与清理清单 |

## 2026-11-24 清理

清理了 130 个未被现有工程或 Python 测试引用的历史构建目录。删除前，将其中 575 个非编译产物文件归档至本机 `archives/build-history-20261124-122142.zip`，并逐项回读校验 SHA-256；清单保存在同目录。原始诊断报告、生成记录和夹具可从归档中的原相对路径查找。

保留当前表情版本、相机归位回退版本、现有工程引用的构建、Python 测试依赖的历史构建和离线研究依赖。保留目录中的旧编译中间文件及历史会话中的运行程序副本已清理，用户工程、原始动作素材、会话报告和会话媒体仍保留。旧的 `test-direct-actors.cmd` 仅指向本机 7.1 测试工程，已归档；通用入口继续使用 `start-studio.cmd`。

共释放约 14.89 GiB。历史会话目录用于查阅记录，清理后不能作为完整可运行会话重新连接；从 GUI 创建新会话即可。文档中的历史构建路径是当时实测位置，已清理版本的调查资料应从本机归档查找。

## 验证入口

当前 Windows x64 构建及核心/模拟运行时检查：

```powershell
.\scripts\build-7.2.ps1
python -m unittest discover -s tests -p 'test_*.py' -q
```

Python 集成测试目前还引用多个历史 `build-studio*` 目录及其夹具；本次清理保留了这些依赖。新检出仓库不能仅凭第二条命令重建这些本地测试输入。实时游戏测试是单独的验证流程，清理和提交时不会自动注入游戏。
