# MMD 创作功能状态（2026-10-13）

当前适配范围为指定 EXE 指纹的原神国服 7.1.0、男主角色。证据分别注明，不把核心或界面功能存在视为实机功能已经完成。

| 功能 | 当前状态 | 证据与边界 |
|---|---|---|
| VMD 动作、时间轴、暂停/跳转/循环 | 已实机验证 | 统一时钟，52 骨骼 FK，支持手指 |
| Root/Center/Groove 视觉根位移 | 已实机验证 | 不移动网络实体或碰撞体 |
| 双腿与脚尖 IK | 已实机验证且有用户画面反馈 | 实际根高度修正；固定平面，未做地形查询 |
| PCM WAV、音频控制 | 已实机验证 | WinMM；音频偏移另有样本级自动验证 |
| 相机 VMD 位置/旋转/FOV | 写入与恢复已实机验证 | 首帧对齐当前机位；最终渲染时序未确认 |
| 手动机位与 FOV 覆盖/复位 | 写入与恢复已实机验证 | 在角色会话中使用；尚无 WASD/鼠标操作 |
| 运镜关键帧与 VMD 导出 | GUI 与 C++ 采样器往返通过 | 从输入参数编排，尚非实时相机采集 |
| GUI、工程、set.ini 导入 | 自动检查通过 | 表情/额外舞者通道仅保留与提示，尚不播放 |
| MP3/其他格式音频 | 未接入 | 当前明确拒绝，需先转换 PCM WAV |
| 相机驱动接管、舞台锚点/跟随、实时录制 | 未完成 | 游戏仍可能覆盖相机；需要验证更新阶段或驱动租约 |
| 表情、口型、眨眼与视线 | 未接入客户端 | VMD morph 可解析；需探测原神面部参数和覆盖行为 |
| 捩骨与更多角色比例适配 | 未完成 | 当前源骨架为近似预设，仅验证男主 |
| 斜坡/台阶地形贴合 | 未完成 | 需可靠地面查询及动作接触语义 |
| 服装/头发物理控制、HUD 显隐 | 未接入 | 需定位对象并建立独立恢复逻辑 |
| 多人同台 | 未接入 | 作品路径可保留；需实际可渲染演员方案 |
| 逐帧高质量输出、内置录屏 | 未接入 | 当前可配合外部录屏 |

最新相机、GUI、作品导入与验证明细见 [STUDIO_RESULTS.md](STUDIO_RESULTS.md)。表情与场景控制是后续客户端适配重点；现阶段仍不能宣称已完整复刻 EIEM。
